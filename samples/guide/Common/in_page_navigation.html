In-Page Navigation
- 콘텐츠가 긴 페이지에서 현재 위치를 안내하고 원하는 섹션으로 바로 이동할 수 있도록 돕는 페이지 내 탐색 목록입니다.
- Mobile(767px 이하)에서는 좌측 고정폭 목록 대신 select형 드롭다운으로 바뀝니다(Figma node-id 2909-46363/46365 실측). <ul>은 그대로 두고 select 트리거(.navSelect)만 추가한 뒤, 클릭 시 <ul>이 드롭다운 패널로 펼쳐지는 방식입니다.
- 항목들이 실제로는 각각 다른 화면으로 이동하는 링크(<a href>)라서, listbox/option이 아니라 disclosure(펼침) + aria-current 조합으로 접근성을 맞췄습니다 - 기존 [data-toggle-infobox]/[data-menu-trigger]와 동일한 패턴입니다. 트리거는 aria-expanded로 펼침 상태를, 현재 페이지에 해당하는 링크는 aria-current="page"로 표시합니다.
